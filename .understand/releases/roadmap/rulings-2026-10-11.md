# Rulings, 2026-10-11

The Engineer's rulings from the 2026-10-11 session, continuing the numbering of `rulings-2026-10-10.md`.

| # | Question | Ruling |
| --- | --- | --- |
| R-60 | Too many small PRs into `main` | **Consolidate.** Docs and board PRs merge as one (#266 replaces #237, #250 and #252). Toolchain PRs merge as one (#259 takes #236 and #244). Bug fixes stay on their own. |
| R-61 | Merge method ("we rebase so frequently") | **Hybrid, with a merge queue.** Slice PRs into `feature/*` merge with a merge commit, so the children in a stack need no restack. `feature/*` → `main` stays a squash, through a merge queue on `main` that replaces the strict "up to date" loop (ships with #259). GitHub's "Rebase and merge" was rejected because it always mints new SHAs. |
| R-62 | Stale remote branches | **Delete** those with closed PRs, plus the three folded into #266 (11 deleted). The five that never had a PR stay until checked. |
| R-63 | Who reviews what | **The Engineer reviews only PRs into `main`.** Copilot and QA review slice PRs, plus security when it applies and any other team that fits. Claude merges anything not going into `main`. Domain forks still stop for the Engineer on any branch. |
| R-64 | den.proto (#255) under R-63 | **Keep D-19.** The Engineer reads den.proto's text before #255 merges, because it's the API contract that later slices build on. |
| R-65 | Blank names (amends R-53) | **Strip, then refuse the blank ones.** At both ends, strip whitespace, fillers (U+3164, U+2800, …) and invisible format characters. Inside a name, strip fillers and zero-width spaces, but keep ordinary spaces and the joiners and variation selectors that emoji (👨‍👩‍👧, ❤️) and scripts such as Persian need. A name that is empty after stripping is refused. U+2028 and U+2029 stay refused anywhere (R-53). |
